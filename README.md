# Integrated USUM capture development

This development version brings Loopy USB and NTR wireless bottom-screen capture into the bot. Connection settings and a preview are managed from one application, and encounter detection consumes direct frames independently of window visibility.

See [installation and user guide](usum_pi_bot/README.md). Keep this installation separate until it passes a real-console test on both sources. The older Windows implementation is unchanged; the original emulator guide is in [README.emulator.md](README.emulator.md).
